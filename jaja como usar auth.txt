Backend
En el backend, la "protección" de rutas y demas se hace usando Depends de fastapi en los endpoints de los routers , esta en src/auth/dependencies.py

- get_current_persona | Usuario autenticado (cualquiera activo)
- tiene_permiso_administrar | ver si es admin
- tiene_permiso_operar | ver si es operador

ejemplo 
def ver_datos(usuario_actual: Persona = Depends(get_current_persona))
    # usuario_actual contiene los datos de la Persona autenticada

ejemplo de proteccion
def crear_equipo(
    datos: EquipoCreate,
    db: Session = Depends(get_db),
    admin: Persona = Depends(tiene_permiso_administrar)  # Si no es admin devuelve 403
)

def registrar_control(
    operario: Persona = Depends(tiene_permiso_operar)  # Si no tiene capacidad operar devuelve 403
):


Frontend

En el frontend hay 2 niveles de protección:
- Protección a nivel URL Usando AuthLayout y ProtectedRoute
- Protección a nivel ui ocultando o mostrando botones y enlaces según el usuario con useAuth()

ejemplo de proteccion
usas <AuthLayout /> en element si el usuario no inició sesión, se redirige automáticamente a iniciar-sesion (para operarios)

ejemplo

 {
            path: 'personal',
            element: <AuthLayout/>,
            children: [
              { index: true, element: <PersonalListPage /> },
              { path: 'new', element: <NuevaPersonaPage /> },
              { path: ':id/edit', element: <EditarPersonaPage /> },
            ],
          }
}

si la ruta necesita perms de admin usas <ProtectedRoute requireAdmin />

{
            path: 'equipos',
            children: [
              { index: true, element: <EquiposPage /> },
              {
                element: <ProtectedRoute requireAdmin />,
                children: [
                  { path: 'new', element: <NuevoEquipoPage /> },
                  { path: ':id/edit', element: <EditarEquipoPage /> },
                ],
              },
            ],
          }
}

para proteger solo una accion especifica (por ejemplo, permitir ver la lista pero solo admin puede crear)


{
  path: 'insumos',
  children: [
    { index: true, element: <InsumosListPage /> }, // Cualquiera logueado puede ver la lista
    {
      element: <ProtectedRoute requireAdmin />,     // Solo admin puede crear o editar
      children: [
        { path: 'new', element: <NuevoInsumoPage /> },
        { path: ':id/edit', element: <EditarInsumoPage /> },
      ],
    },
  ],
}


Para mostrar o ocultar elementos de la ui se usa useAuth


import { useAuth } from '../hooks';

export function MiComponente() {
  const { currentUser, logout } = useAuth();

  return (
    <div>

      // Mostrar botón solo si tiene capacidad de administrar
      {currentUser?.administrar && (
        <button onClick={() => alert("Acción de Admin")}>
          Panel Administrador
        </button>
      )}

      //
      {currentUser?.operar && (
        <button onClick={() => alert("Registrar tarea")}>
          Operar Equipo
        </button>
      )}
    </div>
  );
}
